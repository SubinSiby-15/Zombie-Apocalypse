# Zombie Survival Runner

A 3D zombie survival game built with Unity and C#. Players must survive against waves of zombies while running, avoiding danger, and eliminating enemies. The gameplay is inspired by the endless-running style of Temple Run, combined with zombie combat mechanics.

## 🎮 Game Overview

In Zombie Survival Runner, players run through a dangerous environment filled with zombies. The objective is to survive as long as possible, defeat zombies, and achieve the highest score.

### Features

- 🧟 Zombie enemies with AI behavior
- 🔫 Shooting and combat system
- 🏃 Endless runner-style gameplay inspired by Temple Run
- ❤️ Player health and damage system
- 🌊 Zombie wave spawning system
- 🎥 Third-person camera using Unity
- 🎬 Character and weapon animations
- 💀 Zombie death and attack animations
